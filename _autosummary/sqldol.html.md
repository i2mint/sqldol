# sqldol

sql with a simple (dict-like or list-like) interface

### Modules

| [`access`](sqldol.access.html.md#module-sqldol.access)     | Read Microsoft Access files (`.mdb`, `.accdb`: Jet3, Jet4, ACE) as Mappings and as engines.   |
|----------------------------------------------------------------------------------|-----------------------------------------------------------------------------------------------|
| [`base`](sqldol.base.html.md#module-sqldol.base)         | Base objects for sqldol                                                                       |
| [`ops`](sqldol.ops.html.md#module-sqldol.ops)           | Leaf-level operations, as free functions over the caller's (possibly wrapped) store.          |
| [`sql_base`](sqldol.sql_base.html.md#module-sqldol.sql_base) | Independent legacy DOLs sql with a simple (dict-like or list-like) interface                  |
| [`stores`](sqldol.stores.html.md#module-sqldol.stores)     | Higher level stores for sql data                                                              |
| [`util`](sqldol.util.html.md#module-sqldol.util)         | Utils for sqldol                                                                              |
